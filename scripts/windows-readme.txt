PIKSEL QAL'A v{VERSION} — Windows dasturi
=========================================

Retro piksel RPG. Windows 10 va 11 uchun.
O'rnatish shart emas, admin huquqi kerak emas, internetsiz ishlaydi.


QANDAY OCHISH
-------------
1. ZIP arxivni papkaga chiqaring: arxivni sichqonchaning o'ng tugmasi bilan
   bosing -> "Извлечь все" / "Extract all".
   (Arxiv ichidan to'g'ridan-to'g'ri ochmang.)
2. "Piksel Qala.exe" ni ikki marta bosing.

"Windows защитил ваш компьютер" / "Windows protected your PC" (SmartScreen)
oynasi chiqsa — bu dastur imzolanmagani uchun, xavfli emas:
   "Подробнее" / "More info" (Batafsil) ->
   "Выполнить в любом случае" / "Run anyway" (Baribir ishga tushirish).
Bu faqat birinchi marta so'raladi.

F11 — to'liq ekran. Oyna o'lchami eslab qolinadi.
Boshqaruv: WASD yoki strelkalar — yurish, Space — hujum, Shift — sakrash/dash,
Esc — pauza, M — ovoz.


AGAR DASTUR OCHILMASA
---------------------
Dasturga Microsoft Edge WebView2 kerak (Windows 11 va yangilangan Windows 10
da bor). Yo'q bo'lsa, dastur buni o'zbekcha xabar bilan aytadi va yonidagi
"Piksel Qala.html" ni (portativ versiya) brauzerda ochishni taklif qiladi.
"Piksel Qala.html" ni o'zingiz ham ochishingiz mumkin — u Chrome, Edge yoki
Firefox'da internetsiz ishlaydi.


SAQLANISHLAR
------------
Rekordlar, oltin, qahramonlar va yutuqlar shu kompyuterdagi foydalanuvchi
papkasida (AppData) saqlanadi. Dasturni yangilasangiz yoki .exe ni boshqa
papkaga ko'chirsangiz ham o'chmaydi.

Boshqa kompyuter yoki telefonga o'tkazish: Sozlamalar -> Umumiy ->
Progressni ko'chirish -> kodni nusxalang va yangi joyda kiriting.
