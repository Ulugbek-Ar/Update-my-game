PIKSEL QAL'A v{VERSION} — portativ versiya
==========================================

Retro piksel RPG. O'rnatish shart emas, internet ham shart emas.


QANDAY OCHISH
-------------
1. ZIP arxivni oching va ichidagi fayllarni istalgan papkaga
   (masalan, Ish stoli yoki fleshka) chiqarib oling.
   ("Извлечь все" / "Extract all" tugmasi.)
2. "Piksel Qala.html" faylini ikki marta bosing — o'yin brauzerda ochiladi.
3. Agar fayl boshqa dasturda ochilsa: faylni sichqonchaning o'ng tugmasi
   bilan bosing -> "Открыть с помощью" / "Open with" -> Google Chrome,
   Microsoft Edge yoki Mozilla Firefox.

Kerakli brauzer: Google Chrome 80+, Microsoft Edge yoki Firefox 78+.
Brauzer juda eski bo'lsa, o'yin buni o'zbekcha xabar bilan aytadi.

Boshqaruv: WASD yoki strelkalar — yurish, Space — hujum, Shift — sakrash/dash,
Esc — pauza, M — ovoz. Tugmalarni Sozlamalarda o'zgartirish mumkin.


SAQLANISHLAR QAYERDA
--------------------
Rekordlar, oltin, qahramonlar va yutuqlar SHU KOMPYUTERDAGI SHU BRAUZERDA
saqlanadi (fayl ichida emas).

- Boshqa brauzerda yoki boshqa kompyuterda ochsangiz — o'yin boshidan
  boshlanadi.
- Brauzer tarixi/ma'lumotlari tozalansa ("Очистить историю", cookie va sayt
  ma'lumotlari) — saqlanishlar ham o'chadi.
- Faylni har doim bir joydan oching (masalan, Ish stolidan): ba'zi
  brauzerlarda (Firefox) saqlanishlar fayl turgan joyga bog'liq.


PROGRESSNI BOSHQA JOYGA KO'CHIRISH
----------------------------------
Progressni ko'chirish kodi orqali oltin, qahramonlar va yutuqlarni boshqa
kompyuter, brauzer, telefon (Android ilova, Telegram) yoki saytga o'tkazing:

1. Eski joyda: Sozlamalar -> Umumiy -> Progressni ko'chirish -> kodni
   nusxalang (yoki yozib oling).
2. Yangi joyda: Sozlamalar -> Umumiy -> Progressni ko'chirish -> kodni
   kiriting.

Maktab kompyuterida o'ynasangiz, ketishdan oldin kodni saqlab qo'ying!
